# C 인벤토리 아트 적용 기록

출처는 C가 전달한 `MEMORIDE_C_INVENTORY_ART_45_CANDIDATE_20261112_223330_KST.zip`이다. 전달 후보의 파일명과 콘텐츠 ID를 유지했다. 이미지 생성·Blender 스크립트는 이번 적용 작업에서 실행하지 않았다.

- `compatible_256`: 승인 캐릭터 표정/의상 36장과 음식·의상·장식 썸네일 9장을 기존 경로에 교체했다.
- `highres`: 캐릭터 36장을 `app/src/main/assets/avatars/approved_hd/`에 원본 바이트 그대로 추가했다. 인벤토리와 확대된 섬 캐릭터만 이를 우선 사용한다. 로더는 1024px 입력을 768px로 디코딩하고 HD 캐시를 6장으로 제한하며, 파일이 없으면 기존 256px 프레임으로 폴백한다.
- 기존 슬롯별 섬 장식 레이어 PNG는 교체하지 않았다. 새 슬롯 미리보기와 실제 배치는 모두 기존 레이어를 사용한다.
- 81장의 파일 SHA-256은 전달 ZIP의 `DELIVERY_MANIFEST.json`과 일치한다. 대응 경로·해시는 [기록](asset_manifests/C_INVENTORY_ART_20261113.json)에 있다. 이는 파일 동일성 확인이며 앱 표시 품질 인수가 아니다.

C의 설명에 따르면 캐릭터/의상은 사용자가 제공한 프로젝트 아트 원본을 렌더했고, 일부 아이템은 기존 프로젝트 SVG를 참고해 제작한 3D 후보이다. 외부 연결 라이브러리/텍스처가 없다는 C의 감사 기록은 전달 자료의 주장으로 보존하며, 이번 작업에서 독립 Blender/권리 감사를 수행한 것은 아니다. 프로젝트 제공 자산의 기존 출처 기록을 따르며 새 CC0 등 별도 라이선스를 부여하지 않는다.

사용자 요청에 따라 최종 적용 코드의 빌드·시험·실기기 표시 검수는 실행하지 않았다. 크기·선명도·표정/의상 조합과 섬 장식 위치의 최종 확인이 남아 있다.
