# A03 external navigation and normal-build destination capture

A owns launch, read-only SDK capture and explicit parked-return admission. No shared DTO or B save schema change.

- MainActivity launches the verified Pleos system navigation package ai.umos.maps.android.navigation.app using its launcher Intent. Package visibility is limited to that app and the verified Navi service. Gate/foreground/owner are rechecked after resolving and before starting. Missing app, denial and exceptions stay failed; OS start acceptance never means arrival/reward or guaranteed guidance success.
- NaviHelper3.0.5 and NAVI_ROUTE read permission move from debug to main. The release no-op is removed. Search/custom-map permissions and error injection remain debug-only. No foreground service, overlay, DO declaration, fake parking or SDK arrival-to-reward conversion.
- App-process observer survives Activity pause; listener events only update one A-owned navigation hint. Query-in-flight/error/timeout block old confirmation; refresh remains available once the query ends, including unknown/expired/unregistered hints. Timeout only releases input with error, not a successful navigation/arrival outcome. Current normal-build destination cards use the existing USER_CONFIRMED/manual original receipt pipeline.
- Route calculation is not arrival. Only exact registered Catalog reference points can enter the current REGION confirmation; arbitrary POI proximity is not a city boundary. Coordinates/timing are not copied as measured distance/time. NEEDS_REVIEW remains an explicit user declaration path; cancelled/consumed/generation-stale hints stay blocked.
- SDK callbacks do not carry query IDs. Epoch/generation fencing discards observed cross-route responses and unsolicited destination payloads without an outstanding query, but every possible late platform response cannot be attributed. No auto reward depends on those payloads. Process-dead/background-long-term/other navigation providers remain limitations.
- NavigationLaunchRehearsalActivity is debug-only: isolated B file and in-memory hint, actual platform gate and real production SDK observer. It injects one labelled launch failure, then uses actual production launcher on retry. It is not a release/product route and never resets the default game.
