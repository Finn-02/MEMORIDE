## 파트별 PR에 남길 증거

- A: 실제 Pleos 창별 bounds/density/insets, 공식 Window Policy와 Manifest 방향 설정 확인, 주차/제한/UNKNOWN·내비 복귀·resize·pending 저장 흐름. 일반 Android fake를 실차 주차로 표시하지 않음.
- B: S01/S02/S03의 각 창 배치와 실제 승인 PNG, selected/locked/busy 상태, 큰 글자·터치 도달. 원래 B 저장/원본 영수증을 유지하며 새 REGION 성장 회귀를 별도 제출.
- C: S04 빈 지도/발견/선택 상세를 각 창에서 확인, 네 시연의 resize·복귀 상태 보존, 지도 출처/아이콘 터치영역. 411dp 단독 검수로 Pleos 완료 표시 금지.
- PM: S05/S06 실제 문구·데이터 없음·새 지역/재방문·저장 오류·ack 실패, 물리 글자/대비, 실제 제출 이미지·자산 권리. Figma 예시 수치·날짜를 실제 값으로 사용하지 않음.

새로운 기능 범위나 안전 제한을 바꿔야 하는 경우에만 영향과 근거를 조정한다. 통상적인 간격·글자 줄바꿈·색상 대비 보정마다 PM 승인을 기다리는 절차를 만들지 않는다.
