# 1 제품 목표와 적용 범위

제품명은 MEMORIDE, 대표 문구는 Ride Becomes a Memory다. 기존 카일랜드 섬 세계관을 유지한다. 일상과 지역 여행이 현재의 섬·기념품으로 남는 경험을 구현하며 상세 추억 연대기는 향후 계획이다. 브랜드 스토리는 docs/BRAND.md, 이름과 기술 ID의 구분은 18장을 따른다.

MEMORIDE는 자동차로 함께한 일상과 여행이 캐릭터와 섬에 반영되는 차량 연동형 라이프 시뮬레이션 게임이다. 이번 목표는 4명이 14일 동안 핵심 흐름을 구현하고, 초기화 후 반복해서 보여줄 수 있는 Android 프로토타입을 만드는 것이다. 일반 소비자 출시, 실제 차량 간 통신, 주행 중 게임 사용 허가까지 달성하는 계획은 아니다.

이 명세는 팀 사이의 경계와 공통 동작을 정한다. 담당자는 자기 파트의 클래스 구성, 화면 내부 배치, 함수 분해와 세부 테스트를 자율적으로 설계한다. 전 기능에 대한 상세 설계를 PM에게 다시 요구하지 않는다. 다른 파트의 계약, 안전 제한, 저장 형식, 추가 비용, 제출 범위를 바꿀 때만 영향받는 담당자와 조율한다.

## 1 1 문서 사용 순서와 우선순위

팀원은 README, AGENTS.md, 자기 역할 카드, 공통 계약을 먼저 읽고 해당 기능의 장만 추가로 읽는다. 큰 명세 전체를 AI에 매번 입력하지 않는다. 제품 정체성·포함 범위는 Concept Baseline 1.2, 구현 경계·동작은 이 specification, 실제 타입은 저장소의 core/contract를 기준으로 한다. 셋이 충돌하면 조용히 한쪽을 선택하지 말고 작은 변경 기록으로 맞춘다. MD가 개발 중 편집 원본이며 DOCX는 공유용 스냅샷이다.

설계 결정은 제안의 강도를 구분한다. 필수는 완료 판정에 쓰고, 기본안은 더 단순한 동등 대안으로 변경할 수 있으며, 조건부는 환경에서 검증된 경우에만 넣는다. 예시 값과 시간 목표는 검증된 실측값이 아니다. 이 문서를 읽거나 정적 검사에 통과한 것만으로 앱 구현·안전성·무결함이 증명되지는 않는다.

## 1 2 사용자 가설과 가치

초기 대상은 어린 자녀와 이동하는 가족이다. 실제 인터뷰로 확정한 페르소나가 아니라 검증할 사용자 가설이다. 부모는 출발·도착 때 짧게 확인하고, 동승 가족은 함께 음식·의상·장식을 고른다. 운전자에게 차 안에서 오래 머무르거나 추가 운전을 요구하지 않는다. 아이에게 식사·수면 같은 의무 관리나 접속하지 않은 페널티를 주지 않는다.

| 상황 | 사용자의 작은 목표 | 제품 반응 | 이번 검증 |
|---|---|---|---|
| 출발 전 | 내 캐릭터 확인 | 섬과 현재 의상 표시 | 30초 안에 꾸미기 진입 가능한지 관찰 |
| 이동 개념 체험 | 함께 간다는 느낌 | 모의 내비의 작은 캐릭터 영역 | 의상 유지와 정보 가림 여부 확인 |
| 도착 후 | 무엇이 달라졌는지 확인 | 짧은 브리핑과 성장·기념품 | 설명 없이 변화 이해 가능한지 관찰 |
| 짧은 휴식 | 여행의 지역성을 즐김 | 음식 먹기·의상·장식 적용 | 한 행동 후 바로 종료 가능 |
| 소통 개념 체험 | 정중한 뜻 전달 | 목적 공개와 수락 기반 가상 방문 | 거절하면 방문이 없음을 확인 |

가족의 즐거움, 지역 관심, 정중한 소통은 기대효과다. 고객 유지율, 지역 소비 증가, 사고·보복운전 감소는 측정 전 가설이다. 비슷한 요소가 있는 기존 아이디어가 있으므로 세계 최초·독점적 독창성을 주장하지 않는다. 경쟁력은 차량 여정이 게임 상태로 변하는 일관된 경험, 짧은 이용, 명확한 동의, 사실대로 보여주는 SDK 연결에 둔다. [S01]

## 1 4 제외와 조건부 항목

Car Care, 운전 점수, 평균속도·급제동 판정, 실제 번호판 식별, 실제 V2V, 서버·로그인·결제·멀티플레이, 자유 채팅, 상시 음성 호출, 절차적 섬 생성은 제외한다. 추억 연대기·사진·방문 날짜 이력, 보험사 연락 선택지 안내, 계기판 개인화는 향후 계획이다. 보험 연락은 자동 감지·자동 신고를 의미하지 않는다.

Car Sync는 독립 화면이나 별도 게임 시스템이 아니다. 내비 목적지·도착과 플랫폼 이용 제한을 연결하는 내부 어댑터다. 차량 거리·시간 수집은 이미 검증한 값이 있을 때만 추가하며, 미지원이면 생략한다. 선택한 목적지와 특정 상점 방문 사실은 구분한다. 상호·로고·제휴를 임의로 쓰지 않는다.

## 1 5 제로 추가 비용의 의미

팀이 가진 컴퓨터와 기존에 이용 가능한 AI 구독 범위 안에서 개발한다. Android Studio·공식 에뮬레이터·Git·자체 벡터 자산·로컬 저장을 사용한다. 제품 실행에는 LLM API, 지도 타일 API, 서버, 유료 에셋, 실차 대여가 필요하지 않게 한다. 초기 설치·의존성 다운로드와 실제 Navi Service 경로 탐색에는 네트워크가 필요할 수 있다. 모든 개발 과정이 완전 오프라인이라고 설명하지 않는다.

장비가 에뮬레이터를 실행하지 못하면 무료 소프트웨어만으로 해결되지 않는다. D1에 A와 백업 1명이 실행 가능 여부를 확인한다. 실행 가능한 PC가 하나뿐이면 UI 개발은 Preview·일반 Android 에뮬레이터로 병행하고 Pleos 통합 시험은 시간을 나누어 수행한다. 이 경우 실제 차량 환경 시험의 범위를 낮춰 보고한다.
