# 자산 출처와 사용 기록

초기 설계 패키지의 assets/starter 15개 SVG와 당시 대응 PNG는 프로젝트용 단순 도형 초안으로 기록돼 있다. 팀이 수정해 프로토타입에 사용할 수 있다. 저작권 등록·독점 권리·상표 비충돌을 검증한 문서는 아니다. 이후 교체된 PNG의 제작 방식은 아래 후보별 기록을 따른다.

몸체·얼굴·착용 레이어는 256 x 256 투명 배경이다. 얼굴 레이어는 눈 102와 154 부근, 입 128과 158 부근을 기준으로 한다. 음식·장식은 독립 아이콘이며 캐릭터 손에 보이게 할 때 작은 별도 영역에 축소 배치한다. PNG가 실행 자산이고 SVG는 수정 원본이다.

지역 테마는 게임용 자체 표현이다. 제휴·공식 명물 인증·상점 방문 사실을 뜻하지 않는다. 외부 자산을 추가하면 파일명·공식 출처·라이선스·수정 여부·필요 고지를 이 목록에 추가한다. 원본 강의 자료는 패키지에 재수록하지 않는다.

## 문서 열람용 글꼴

assets/fonts의 NanumGothic Regular·Bold는 Google Fonts 저장소의 원본을 포함했다. 출처는 https://github.com/google/fonts/tree/main/ofl/nanumgothic 이며 동봉 OFL.txt의 저작권·SIL Open Font License 1.1을 유지한다. 문서 열람을 위한 선택 설치이며 게임 실행 자산 15종에 포함하지 않는다. Android 앱에 자동으로 추가하지 않는다.


MEMORIDE 1.2의 제품 표시명 확정은 기존 자체 도형 자산의 제작 경위나 라이선스를 바꾸지 않는다. 문서용 NanumGothic TTF는 배포 ZIP에 포함하며 Git 초기 등록 대상에서는 제외한다. 원본 OFL.txt는 유지한다.

AI 사용 고지: C 작업은 AI 코딩·스크립트·문서 작성 보조를 사용했다. 별도로 생성했던 모모 이미지 생성형 AI 방향 초안 1장은 최종 81개에서 제외했다. 최종 81개는 Blender 렌더 및 축소 결과다. B 원본의 과거 생성형 AI 사용 여부·외부 재료의 최초 출처는 B 확인 대기이며, 전체 제작 이력을 AI 미사용으로 단정하지 않는다.

기존 팀 프로젝트 사용 조건을 승계하며 임의의 CC0·독점권·법적 권리 보증을 추가하지 않는다. 고해상도 로딩·화면 품질·최종 기기 검수는 별도 항목이다.
