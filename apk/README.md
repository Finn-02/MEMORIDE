# APK 제출 위치

아직 APK가 없다. 파트 1은 실제 서명 release를 생성하고 별도 PC에 설치한 뒤 팀명_MEMORIDE_release.apk를 이 폴더에 명시적으로 추가한다. 기본 ignore에서 제외하려면 해당 최종 파일만 git add -f로 추가한다. APK의 source commit·서명·versionCode·실행 환경과 SHA256을 release 기록에 남긴다. 용량 제한을 넘으면 공식 안내에 따라 GitHub Releases를 사용한다. 파일이 생기기 전에는 README에 다운로드 성공 링크를 만들지 않는다.
